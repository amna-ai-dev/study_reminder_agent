# Study Reminder Agent 📚

A beginner-friendly Python project that helps students manage their study sessions with a simple timer.

## Features
- Takes the student's name.
- Allows subject selection.
- Accepts study duration in minutes.
- Starts a study timer.
- Displays a reminder when study time is over.
- Encourages students to take a short break.

## Technologies Used
- Python
- Time Module

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run this command:

```bash
py study_reminder.py
```

## Project Purpose
This project was created to practice Python basics, user input, variables, type conversion, and the time module.
